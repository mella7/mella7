# Icon sources

- Most tiles: [tandpfun/skill-icons](https://github.com/tandpfun/skill-icons) (MIT, see LICENSE-skill-icons).
- Helm, ArgoCD, Cilium, Falco: official project icons from [cncf/artwork](https://github.com/cncf/artwork),
  placed on a skill-icons style tile. Used under the Linux Foundation trademark guidelines to name tools I use.
- `si-*.svg`: [Simple Icons](https://simpleicons.org) (CC0, see LICENSE-simple-icons).

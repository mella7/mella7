## 🔧 Selected projects

**[Container Networking from Scratch](https://github.com/mella7)** — Rebuilt container networking without Docker: Linux namespaces, veth pairs, a bridge, and iptables NAT, wired together by hand. The best way I found to actually understand what a CNI plugin does.

**[Kubernetes Operator — ProjectClaim CRD](https://github.com/mella7)** — A custom controller that provisions self-service namespaces with quotas, RBAC, and network policies from a single declarative claim. Written in Go with controller-runtime.

**[cloudstack-dc](https://github.com/mella7)** — Full-stack automation platform for Apache CloudStack deployments: form-driven UI, live-streaming provisioning logs, and a Next.js + SQLite backend. Tested end-to-end on real 4-node hardware.

**[DevSecOps Platform on AWS](https://github.com/mella7)** — Cloud-native delivery pipeline on EKS with Terraform, ArgoCD, and GitHub Actions, with security gates at every stage (SonarCloud, Snyk, Trivy) and Falco for runtime detection.
